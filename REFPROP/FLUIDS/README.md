# `REFPROP/FLUIDS/`

Custom mixture-EOS coefficients for the He-Ne, He-Ar, and Ne-Ar binary
mixtures developed in the prior work of [Tkaczuk *et al.* 2020](https://doi.org/10.1063/1.5142275).
The file `HMX.BNC` here must be merged into REFPROP's own `FLUIDS/HMX.BNC`
before the analysis pipeline can compute mixture properties; see the
parent [`../README.md`](../README.md) for the merge procedure.
