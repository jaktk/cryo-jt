# `REFPROP` directory

This directory contains the only non-standard part of REFPROP10 - equations of state for the mixtures of:
- Helium - Neon;
- Helium - Argon;
- Neon - Argon.

The reducing parameters and the departure functions need to be copied to the `HMX.BNC` file of local REFPROP installation to run the analysis from this repo.
