# `p_T_pairs`

This directory contains the pressure-temperature pairs extracted from the `raw-data` directory.

All values in the `csv` files in this directory are means of 5 measurements. Standard deviation `STD` and standard expanded uncertainty `EXP_UNC` for 95% confidence interval ($k=1.96$) are calculated.

Naming convention of files follows this pattern: "fluid"\_"inlet temperature for the Joule-Thomson transformation"\_"inlet pressure for the Joule-Thomson transformation".
