#     newtxsf, for matplotlib's text.usetex in the publication style sheet
#     src/jced.mplstyle (Helvetica text and sans-serif math). To regenerate
#     the figures without LaTeX, set text.usetex to False in that style sheet
#     (the fonts will then differ from the published figures).
